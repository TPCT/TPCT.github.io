# Architecture — Islam Elsayed portfolio (https://tpct.github.io)

Owner: Tech Lead · Date: 2026-10-21 · Size: M · Inputs: `brief.md`, `prd.md`, `ux.md`, `content.json`.
`ux.md` is the normative design system (tokens, markup, behaviour). This document decides **how** it is built.

## 1. Approach

**Zero-dependency static build.** Plain HTML/CSS/vanilla JS, rendered from `src/content.json` by a small Node (ESM) build script into `dist/`. No framework, no npm runtime or dev dependencies, no bundler. GitHub Actions runs the build, the tests and the confidentiality check, then deploys `dist/` to GitHub Pages.

### Alternatives considered
| Option | Verdict |
|---|---|
| Astro (static output) | Rejected. Adds ~200 MB of node_modules, a lockfile to maintain and a framework to learn, for one page plus a 404. Nothing in the PRD needs components, MDX or image pipelines. |
| Eleventy / other SSG | Rejected for the same reason; templating is trivial here. |
| Hand-written `index.html` | Rejected: PRD requires "adding a project = edit content.json only" and build-time validation of content. |
| **Node build script + template-literal renderers** | **Chosen.** ~1 small file per concern, full control over byte-exact markup from ux.md, CSP hash computed at build time, zero supply-chain surface, builds in < 1 s. |

## 3. Build pipeline (`scripts/build.mjs`)

1. Read `src/content.json`. `JSON.parse` failure → throw with file name + message.
2. `validateContent(c)` → if any errors, print each on its own line and exit 1 (CLI) / throw (API). Fails on: missing required keys, project `category` not in `categories`, duplicate project ids, unknown `kind`, open-source without a valid `repoUrl` (`^https://github\.com/TPCT/[A-Za-z0-9._-]+$`), non-integer `year`, nav `href` not starting with `#`. A `repoUrl` on a case study is only a warning (renderer ignores it — PRD US-15 edge).
3. Clean `outDir` (default `dist/`), copy `public/` recursively.
4. Concatenate `src/styles/*.css` (sorted by name) → `assets/site.css`; `src/scripts/*.js` (sorted) → `assets/site.js`. Each gets a cache-buster `?v=<first 10 hex of sha256(content)>` in the HTML links (Pages caches ~10 min).
5. Render `index.html` and (from T-003) `404.html`, `robots.txt`, `sitemap.xml`, `site.webmanifest`.
6. Exported API: `export async function build({ outDir = "dist", root = <repo root> } = {})` returns `{ outDir, files: string[] }`. CLI guard: run only when `import.meta.url === pathToFileURL(process.argv[1]).href`. Tests call `build({ outDir: <tmpdir> })`.

**Rendering rules.** Renderers are pure functions `(c, ...) => string` using template literals. Every content string goes through `esc()` (`& < > " '`), every attribute value through `attr()` (same escaping). No raw HTML in content.json. No inline `style=""` attributes and no inline event handlers anywhere (CSP).

## 4. Security / CSP

`<meta http-equiv="Content-Security-Policy">` placed directly after `<meta charset>` and viewport:

```
default-src 'self'; script-src 'self' 'sha256-<HASH>'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'; manifest-src 'self'
```

- `<HASH>` = base64 sha256 of the exact inline theme script body from ux.md §6, **computed by the build** from the same string constant that is emitted (no manual re-hash).
- No `style=""` attributes → the ux.md `style="--i:N"` stagger is replaced by `:nth-child(N)` rules setting `--i` in CSS (decision D6). JS may set styles through CSSOM (`el.style.x = ...`), which CSP allows.
- JSON-LD (`type="application/ld+json"`) is a data block, not executed; allowed.
- External links: `target="_blank" rel="noopener noreferrer"`.

## 5. Browser JS

One deferred file `/assets/site.js` (`<script src defer>` at the end of `<head>`), ES2020, no modules, each source file an IIFE that no-ops if its DOM hooks are absent (so the same bundle runs on `/` and `/404.html`). Budget ≤ 30 KB gzip (expected < 6 KB).
- `10-theme.js`: toggle (ux §4.2/§6), localStorage wrapped in try/catch.
- `20-nav.js`: mobile menu disclosure (< 768px via `matchMedia`), in-page anchor focus enhancement.
- `30-filter.js`: category × kind filter, counts, live region, empty state, URL state (ux §4.7).
- `40-copy.js`: copy email (ux §4.10).
- `50-scrollspy.js`: IntersectionObserver `aria-current` (ux §4.2).

No-JS: `<html class="no-js">`; inline script swaps to `js`. Filters, theme toggle, menu button and copy button are server-rendered with `hidden` and only revealed by JS.

## 7. Confidentiality guard (`scripts/check-confidential.mjs`, T-003)

- Scans (a) every file under `dist/` and (b) every file from `git ls-files -z --cached --others --exclude-standard` (tracked + would-be-committed; gitignored paths such as `.company/private/` are never read). Skips binary files (NUL byte in the first 8 KB) and the script's own test fixtures dir.
- Rule 1: regex `/[a-z0-9-]+\.(shiftcodes\.net|xcutor\.net)/i` → any match fails. The bare `shiftcodes.net` passes.
- Rule 2: denylist from `.company/private/denylist.txt` (gitignored, optional). One literal term per line, `#` comments and blank lines ignored; matched case-insensitively as a whole token (`(?<![A-Za-z0-9_-])term(?![A-Za-z0-9_-])`, term regex-escaped). File missing → print `denylist: not found, skipped` and continue (CI case).
- Output: `file:line: <rule>` per hit — **never print the matched denylist term itself** (CI logs are public); print the rule name and term index only. Exit 1 on any hit, 0 otherwise. Also fails if `dist/` is missing.
- The denylist file is created and maintained by the **lead (Claude)** from `.company/private/readmes.md` (`vis: private` names, minus generic words and names that are public in content.json such as "AIC"). Codex never sees or writes it.

## 8. Images and font (T-003)

- **Font:** Archivo variable (OFL 1.1) subset to wght 400–800, wdth 100–125 and the ux.md §2.2 unicode list → `public/assets/fonts/archivo-var.woff2` (target ≤ 80 KB, hard cap 120 KB) + `OFL.txt`. Built once with fonttools in a throwaway venv outside the repo (`scripts/build-font.sh` documents it). Fallback if fonttools/pip cannot be used: `@fontsource-variable/archivo` (`npm pack`, outside the repo) `files/archivo-latin-wdth-normal.woff2`. Committed; never fetched at runtime or in CI.
- **OG + icons:** `scripts/render-images.mjs` (dev only) generates `src/images/og-image.svg` from content per ux.md §8, renders it in headless Chromium through `playwright-core` resolved from `$PLAYWRIGHT_CORE` (path) with `executablePath` from `$CHROME_PATH`, and writes the PNGs into `public/`. ICO is assembled in Node (PNG-in-ICO, 16+32). Outputs are committed; CI never launches a browser.

## 9. Deploy (T-004)

`.github/workflows/pages.yml`, on `push` to `main` + `workflow_dispatch`. `permissions: contents: read, pages: write, id-token: write`; `concurrency: { group: pages, cancel-in-progress: false }`.
- Job `build` (ubuntu-latest): `actions/checkout@v7` → `actions/setup-node@v7` (node 22) → `npm run build` → `npm test` → `npm run check:confidential` → `actions/configure-pages@v6` → `actions/upload-pages-artifact@v5` (`path: dist`).
- Job `deploy`: `needs: build`, `environment: { name: github-pages, url: ${{ steps.deployment.outputs.page_url }} }`, `actions/deploy-pages@v5`.
- Any failing step stops before deploy → live site stays on the previous version (US-20 AC2). No `npm ci` (no dependencies, no lockfile).
- Versions verified 2026-10-21 via `gh api repos/actions/<name>/releases/latest`: checkout v7.0.1, setup-node v7.1.0, configure-pages v6.0.0, upload-pages-artifact v5.0.0, deploy-pages v5.0.1.

## 10. Test strategy

- **Unit/integration (node --test, no deps):** `npm test` = `node --test test/*.test.mjs`. Tests build into an OS tmp dir via `build({outDir})` and assert on the HTML string with regexes/`includes` (no DOM library).
  - content: schema valid, §9 keys present, every category used/declared, slugs unique.
  - build: one `<h1>`, all section ids, nav targets exist, CSP hash matches inline script, no `style="`, no inline `on*=`.
  - projects: card count = projects.length, featured-first order, case-study cards contain no `<a`, OSS cards link exactly `repoUrl`, no `undefined`, chip counts.
  - seo: title/description/canonical/OG/Twitter/JSON-LD, robots, sitemap, manifest, 404 noindex, OG PNG 1200×630 ≤ 300 KB, font magic `wOF2`.
  - confidential: script fails on a planted fixture leak, passes on clean dist.
- **Per Codex round:** only the affected test file(s) + `node --check` on changed browser JS. Leads run `npm run check` (build + all tests + confidentiality) once at the review gate.
- **QA (Claude, after T-004):** Playwright/axe in both themes at 360/768/1024/1440, Lighthouse mobile, no-JS pass, live-site checks (US-14 AC3, US-19 AC1).

## 11. Risks
| Risk | Mitigation |
|---|---|
| Private names leak into the public repo | Rule 1 + denylist in CI and locally; tickets/docs never quote private names; check prints no matched terms. |
| Font tooling unavailable offline | Two acquisition routes; site degrades to the metric-matched fallback if the file is missing. |
| CSP breaks the theme script after an edit | Hash computed from the same constant at build; test asserts it. |
| Lighthouse perf from 1 font + CSS | Single preload, `font-display: swap`, metric-matched fallback, CSS < 40 KB. |
| T-002 is the largest ticket | It touches only section renderers/CSS/JS; if the Codex round overruns, split filter JS into a follow-up fix ticket. |
