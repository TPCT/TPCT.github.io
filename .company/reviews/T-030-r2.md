# T-030 review, round 2 (after T-030-fix-r1)

This round re-checks blocking issue 1 from `T-030-r1.md`: the hero GitHub CTA ran under `.hero__visual` between 1024px and about 1230px.

Browser: headless Google Chrome (`/opt/google/chrome/chrome`) with playwright-core (`/usr/lib/chatgpt/resources/cua_node/lib/node_modules/playwright-core`). `dist/` was served with `PORT=4391 node scripts/serve.mjs`, which was stopped afterwards. Checked in dark and light at 1440, 1280, 1230, 1100, 1024, 768 and 375px.

## Blocking issues
None.

The fix is in `src/styles/40-hero.css`:
- The `nowrap` / `width: max-content` / `max-width` / `flex-shrink: 0` rules are removed.
- The base rule `.hero__ctas { display: flex; flex-wrap: wrap; gap: 12px; }` remains.
- `.btn { width: auto }` applies everywhere, and `width: 100%` only at 480px and below.

The fix also adds a test in `test/sections.test.mjs` ("hero CTA rows stay within the text column"). It asserts there is no `width: max-content` on `.hero__ctas`.

## Non-blocking suggestions
- At 1230–1440px, the GitHub pill's bounding box still crosses the bounding boxes of the decorative `.sc-hero__glow`, the svg `g` and `.sc-sheen`. These are soft halo layers with `pointer-events: none`, so nothing visible covers the button and it still gets the clicks. No action needed.
- The r1 suggestions still apply and can go in a later ticket:
  - remove the dead forced-colors `-webkit-text-fill-color` / `background: none` on `.contact__email`;
  - give the Copy button `btn--primary` instead of `btn--secondary` plus primary styling;
  - use a stricter `ctaSecondary` regex.

## Acceptance criteria
- **No hero CTA overlaps `.hero__visual` content: met.** At every width and in both themes, each button's right edge is within the `.hero__text` right edge.
  - 1024 and 1100: the GitHub pill wraps to a second row at x 32–197, under the other two.
  - 1230, 1280, 1440 and 768: all three sit in one row.
  - 375: the three are stacked at 335px wide each.
- **All CTAs clickable: met.**
  - `elementFromPoint` at each button's centre returns the button at every width.
  - A real click on the GitHub pill at 1100px opened a new tab (popup event fired).
- **Consistent heights: met.** All hero CTAs are 52px at every width, with a 999px radius.
- **No horizontal overflow: met.** `scrollWidth - clientWidth` is 0 everywhere.
- **No console errors: met.** 0 errors in both themes.
- **Everything else from r1 (contact card, copy/fallback, `#contact` navigation and focus, pills, `rel=me`, project and 404 pages): still met.** The r2 diff only touches `40-hero.css` and adds one test.
