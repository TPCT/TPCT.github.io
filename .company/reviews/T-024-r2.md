## Non-blocking suggestions
1. **Letters can stay hidden if `a.ready` rejects.** In `81-kinetic.js`, `if(a&&a.startTime==null)await a.ready;` is inside an `async` callback, so a rejection is unhandled. `ready` rejects if the `intro-out` animation is cancelled before it starts (for example, print or a reduced-motion change at that moment). The letters would then stay at `opacity: .001`.
   - Fix: `await a.ready.catch(()=>{})`, and fall back to `finish()` when `startTime` is still null.
2. **No room left in the byte budget.** The file is 2,398 of 2,400 bytes, and the indentation is inconsistent (mixed 2/4-space). Any further change will need trimming or a budget decision.
3. **Repeat-visit timing is unchanged from r1, which is acceptable.** Letters start at about 0.29–0.44s and settle at 1.12–1.30s. On repeat runs the first move can come slightly before first paint, so the earliest part of the rise is not shown.
4. **Carried over from r1, still open:** the 800ms cutoff, `style=""` left on the accent span after revert, and the duplicated selector in `40-hero.css`.
