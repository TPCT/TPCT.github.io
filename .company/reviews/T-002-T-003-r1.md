## Non-blocking suggestions

1. `src/scripts/30-filter.js` (`canonicalize`): `query.size` needs Chrome 113+, Firefox 112+ or Safari 17+. On older engines `size` is `undefined`, so the query is silently dropped from the URL (filtering itself still works). Use `const qs = query.toString(); ... (qs ? '?' + qs : '')`.
2. `src/scripts/40-copy.js`: if a write is rejected within 2 s of a successful copy, the button keeps saying "Email copied". In the `catch`, clear the timer and restore `labelCopy` / remove `is-copied`.
3. `src/scripts/50-scrollspy.js`: the active section is the last one *inserted* into the Set, not the last one in DOM order. It works in practice because the band is narrow (verified, see below), but ordering by a fixed `ids` array would be more robust.

That leaks the local username/path and makes the SVG machine-specific. Have `scripts/render-images.mjs` write a relative URL (`../../public/assets/fonts/archivo-var.woff2`) into the committed SVG, and use the `file://` URL only for the render copy. Regenerate during the Prism reskin.
5. `src/lib/icons.mjs:6`: trailing whitespace after the `check` entry (`git diff --check` flags it).

7. `html { scroll-behavior: smooth }` should only apply under `prefers-reduced-motion: no-preference`. This is a reskin item, not a blocker here.
8. README.md: the project-structure line `test/  Node tests and fixtures` is slightly off. Fixtures are generated at runtime in a tmp dir, so there is no `test/fixtures/`. Change it to "Node tests".
