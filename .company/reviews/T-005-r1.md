## Blocking issues

1. **`src/styles/30-header.css` (rule `.js .site-header { animation: header-in 600ms var(--ease-out); animation-fill-mode: both; }`): header and mobile-menu glass never blurs.**
   - **Problem:** `fill-mode: both` keeps an opacity/transform animation applied to `.site-header` forever. That makes the header a Backdrop Root, so `backdrop-filter` on `.header-inner::before` (scrolled pill) and on the mobile `#primary-nav` only samples the header's own contents. They never sample the page.
   - **Effect:** 2 of the 3 budgeted glass surfaces are effectively transparent. In the open mobile menu, hero text ("Islam Elsayed", "Systems Architect", "Senior Full-Stack Engineer") shows through crisply and collides with the menu links. That is a readability and polish defect.
   - **Verified in Chromium:**
     - Setting `animation-fill-mode: backwards` on the header restores full blur.
     - Removing `isolation: isolate` from `.header-inner` does **not** fix it, so keep `isolation`.
     - `.schematic`, whose entrance animation sits on the element itself, blurs correctly.
   - **Exact fix:** change that rule to
     `.js .site-header { animation: header-in 600ms var(--ease-out) backwards; }`
     (delay is 0 and the end state equals the resting style, so this is visually identical to `both`, and the animation stops applying after 600ms). Leave every other `.js` hero entrance as is (none of them wraps a backdrop-filter element).
   - **Evidence:** `.company/qa/shots/T-005-375-dark-menu-open.png` (text bleeding through the menu).

2. **`src/styles/30-header.css` (rule `.skip { … transform: translateY(calc(-100% - 16px)); … box-shadow: var(--shadow-pop); }`): the shadow of the hidden skip link leaks into the viewport.**
   - **Problem:** the skip link rests at top −55…−4px, but `--shadow-pop` (`0 12px 32px`) extends about 40px below it. This paints a grey/black smear across the top-left corner (x≈0–200, y≈0–12) on every page load, in both themes. It is clearly visible in light theme.
   - **Exact fix:** add `.skip:not(:focus) { box-shadow: none; }` right after the `.skip` rule. Keep `.skip:focus { transform: translateY(0); }` as is, so the shadow only appears when the link is shown. Do not add `visibility: hidden` (`test/build.test.mjs` asserts against it).
   - **Evidence:** visible at the top-left of `.company/qa/shots/T-005-1440-light-rm.png` and `T-005-1440-dark-motion.png`.

## Non-blocking suggestions

- **Safari ≤ 17 has no blur:** `#primary-nav` (mobile) and `.schematic` declare only unprefixed `backdrop-filter`; Safari before 18 needs `-webkit-backdrop-filter: var(--glass-blur);`. Add it next to each. The test regex already excludes `-webkit-`, so the budget assertion still holds. It can also go into T-006.
- **`src/styles/15-motion.css`:** the last block (view-transition rules) has a stray 2-space indent at top level. Cosmetic.
- **Mobile roles:** at 375px, `.roles` wraps so the `·` separators start the 2nd and 3rd lines ("· Systems Architect"). This is pre-existing behaviour (the same rules were in HEAD), but it looks slightly off on the new design. Consider hiding separators below 400px and adding a small row gap, or stacking the roles in a column there. This could be a T-006 polish item.
- **Mobile prism shard:** at 375px, `.prism__shard--2` (10% of 240px = 24px with a 12px radius) renders as a circle, not a rounded tile. Consider `border-radius: min(12px, 25%)` or `border-radius: 28%` on `.prism__shard`.
- **`scripts/build-font.sh`:** runs the metric one-liner with the venv python (`"$TMP/venv/bin/python3" -I`). That is correct and slightly better than the spec's system `python3` (fontTools is only in the venv).
- **Fonts:** outfit 20,008 B and jakarta 16,636 B (36.6 KB total) are well under the caps.
